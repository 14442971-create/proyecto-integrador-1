# Proyecto Integrador 1 - Biblioteca Escolar con Ejemplares Irregulares

## Alumno
* Juan Angel Emigdio Hidalgo

## Objetivo
Desarrollar una aplicación en C# para la gestión de una biblioteca escolar que administra títulos con distinta cantidad de ejemplares. El sistema permite:
* Representar títulos con distinta cantidad de ejemplares sin dejar celdas vacías en memoria.
* Registrar préstamos reduciendo la disponibilidad y actualizando el contador histórico.
* Ordenar el catálogo de mayor a menor por préstamos históricos mediante **Ordenamiento por Inserción** manual, preservando el orden alfabético en empates.
* Realizar **Búsqueda Binaria** propia por código ISBN y búsqueda secuencial por título.
